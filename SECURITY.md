# Sécurité

Ne signalez pas une faille de sécurité dans une issue : les issues sont publiques. Utilisez le bouton « Report a vulnerability » de l'onglet « Security » de ce dépôt. Seule l'équipe Sirdata voit le rapport.

# Security

Do not report a security vulnerability in an issue: issues are public. Use the "Report a vulnerability" button in the "Security" tab of this repository. Only the Sirdata team can see the report.
